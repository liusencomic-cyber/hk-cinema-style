# 港片导演影像风格库（给生图提示词调用）

## 总原则

1. 风格强度必须克制：保留原图的细节、材质、光影逻辑与海报版式质感，风格只做气质引导。禁止为了风格而风格：不得把全图压成死黑丢掉暗部细节，不得让颗粒/烟雾/偏色糊掉材质纹理。默认力度 = 「原图清晰可辨 + 一眼能感到导演气质」。
2. 风格不只是调色：在不改动原有元素/构图/文字/主体细节的前提下，可加入导演手法元素（雾气、体积光、抽帧拖影、光斑、反射光纹、站位感）。
3. 按图片内容选景别语法定制，不按一张通用公式套。
4. 主导色只落在光与氛围上，禁止落到受保护主体表面：徐克的"金殿"类说法只能形容光线与环境氛围，车漆/肤色/产品本体的颜色与材质永远不动——风格色=光的色，不是物体表面的漆（实践教训）。
5. **风格化元素分级（氛围可入，实体禁入）**：光学/氛围元素——烟雾、体积光柱、光晕 halation、被照亮的雨丝、反射光纹、颗粒、柔焦——默认按该导演语法的「手法元素」入场，风格不入场=只调色=不合格；实体物件——新道具/动物/人物/文字元素（如白鸽、伞）——一律禁止，动实体=动创意。
6. **质感与肤质归风格管辖**：保护清单只锁内容与结构（人物身份/面容特征/姿态/构图/文字/产品外形），禁止写"肤质不变/纹理不变"——每个导演语法的「肤色」行就是肤质指令（王家卫的暧昧朦胧≠杜琪峰的冷灰金属≠许鞍华的完全真实），提示词必须显式调用；所有风格出一样的肤质=风格没进去。

## 导演语法（系列生产固定版）

### 港片语法（固定版 · 黄金年代总风格，不点名导演时的默认项）
- 色盘：**三色混光**——钠灯橙黄（街灯）× 荧光灯青白（店铺/茶餐厅）× 霓虹红品红（招牌），三种市井光源在同一帧里各自为政、共处共存；富士胶片的暖底托住肤色。**与王家卫的分野**：王家卫把光统一成一种情绪（私密双色），港片让街头的杂色光源都活着（公共三色）——前者是作者，后者是市井
- 光：混合色温的街头光场；日戏是亚热带硬阳光+轻微过曝的天+海风灰蓝；夜戏是钠灯橙+荧光青白+霓虹红品红的层层叠加
- 手法元素：富士胶片暖颗粒（夜景 push 增感的粗粝）、略低对比度（不死黑）、密集招牌森林的肌理、骑楼/铁窗花/晾衣竿的市井细节、雨后的湿街
- 运动：手持呼吸感+市井人流的活；自然运动模糊（180°快门）；夜市手持跟拍
- 焦点：街头纪实感——中深景深偏实，夜景特写转浅景深+霓虹散景；自然运动模糊
- 力度：默认中、上限中高——三色混光要"杂而不脏"，过了就是灯光秀
- 肤色：胶片暖底托住真实肤色，不冷不假白
- 不是：不是王家卫（不统一光色）、不是杜琪峰（不压冷蓝）、不是滤镜橙青
- 禁：数码感的纯净、统一色温的滤镜感、空旷留白、死黑高对比
- 一句话：三色混光的街头，旧而闹，有人味

### 王家卫语法（固定版）
- 色盘：浓郁暖金琥珀高光 + 墨绿/深青阴影 + 红色唯一跳色；饱和但克制，艳丽与暗沉对撞
- 光：吝啬的单光源且必须有形状（格栅影/体积光/穿雾）；反射光永远在场（湿地/玻璃/镜面的流动光纹）
- 手法元素：烟雾让光有形；抽帧拖影（动体拖、静体清）；胶片颗粒集中在阴影；轻微暗角
- 运动：抽帧/降格（step-printing）——动体拖影静体清；慢门光轨；偶尔加速抽离
- 焦点：浅景深+前景遮挡（窗格/帘/人肩）的窥视分离感；低速快门/抽帧——动体拖影、静体清晰；柔焦怀旧
- 力度：默认中、上限高——可以暗可以浓，但暗部细节必须活着
- 肤色：暗淡橙黄带暧昧，绝不白皙
- 不是：不是港片三色混光（他要统一）、不是杜琪峰的冷硬
- 禁：全图均匀滤镜感、死黑丢细节、冷蓝主导、大红大绿（那是 2046 单片，不是通用语法）
- 一句话：暗夜里的暖光与孤独

### 杜琪峰语法（固定版）
- 色盘：冷蓝钢灰主导 + 黑金点缀；低饱和
- 光：头顶垂直舞台光切脸；大对比；大面积暗 + 稀疏发光体（路灯/广告牌/车灯）
- 手法元素：几何站位感（人物占位=权力结构）；静到极点；硬边阴影；烟雾慢速扩散
- 运动：静到极点再爆发——镜头少动、人多静（站位即权力）；开枪瞬间是唯一剧烈运动；烟火慢速扩散
- 焦点：深景深硬边锐利、全员清晰（站位要全看清）；无拖影无柔焦
- 力度：默认中高、上限高——对比可以强，但文字区和小物细节必须保
- 肤色：压冷偏灰，金属感
- 不是：不是王家卫的暧昧暖、不是吴宇森的浪漫火光
- 禁：暖、柔焦、拖影、红绿浓艳
- 一句话：冷、硬、静，站位即权力

### 徐克语法（固定版）
- 色盘：东方浓艳——红/金/青按内容择一主导 + 暗底；有画意
- 光：戏剧光（烛光/油灯/天光穿雾）
- 手法元素：烟雾弥漫、风与衣袂飘动、水汽、东方留白
- 运动：快剪+威亚飞天遁地的动线；衣袂与烟尘流动；镜头急推急摇
- 焦点：动作速度感——衣袂/烟尘拖影而面部清晰；画意浅柔焦与锐利交替
- 力度：默认高、上限最高——他是库中唯一允许"满"的，但文字与主体细节仍不可损
- 肤色：戏曲化——浓妆可以艳，轮廓光要勾
- 不是：不是周星驰的市井热闹（徐克是画意不是烟火）、不是现代霓虹
- 禁：现代霓虹、冷灰纪实
- 一句话：浓艳画意的东方侠气

### 周星驰语法（固定版）
- 色盘：明亮高饱和暖金 + 旧城彩色
- 光：黄昏暖金、大排档灯泡、阳光灰尘
- 手法元素：蒸汽油烟、漫画感高光、热闹不压暗
- 运动：漫画式加速与定格；夸张动作的节奏感；热闹场景快切
- 焦点：明快直给、全景深清晰；漫画节奏的快切定格，不虚不拖
- 力度：默认中、上限中——他的力量在饱和与光，不在暗部操作
- 肤色：阳光健康的暖肤色，市井汗光
- 不是：不是许鞍华的平实（他要漫画感）、不是任何冷调
- 禁：暗、冷、压抑、压抑颗粒；禁插画/卡通/动漫画法——漫画感是光影节奏不是画法（实践教训）
- 一句话：热闹明亮的市井烟火

### 刘镇伟语法（固定版）
- 色盘：黄昏金紫渐变 × 月光冷蓝双极
- 光：落日余晖、月色柔光
- 手法元素：夸张大月亮、剪影、浪漫化柔光
- 运动：浪漫慢镜（月下转身/落叶）；奇幻场面的漂浮感
- 焦点：浪漫柔焦+星点光斑散景；月色/光源过曝光晕
- 力度：默认中、上限中高——金紫渐变可以浓，但不糊细节
- 肤色：浪漫化柔光肤质，眼神光带星点
- 不是：不是陈可辛的纪实怀旧（他要奇幻）、不是写实
- 禁：写实硬光、纪实颗粒
- 一句话：荒诞深情的金紫黄昏

### 陈可辛语法（固定版）
- 色盘：怀旧暖黄 + 轻微过曝高光
- 光：柔光、年代感窗光
- 手法元素：薄雾柔光、轻微过曝的回忆感、年代温度
- 运动：柔和小幅手持；歌舞段落流畅调度（如果·爱）；时光流逝的叠化
- 焦点：柔焦+浅景深、轻微过曝高光的回忆感
- 力度：默认轻中、上限中——怀旧是薄纱不是重染
- 肤色：暖黄柔光里的好气色，微过曝高光
- 不是：不是刘镇伟的奇幻、不是许鞍华的无修饰
- 禁：冷硬、强对比、重颗粒
- 一句话：暖黄柔光里的大时代小人物

### 许鞍华语法（固定版）
- 色盘：低饱和米灰自然色
- 光：自然光即窗光
- 手法元素：几乎零风格化、不修饰
- 运动：固定机位长镜头；生活流自然节奏；几乎不运动
- 焦点：自然景深、纪实锐利；零柔焦零拖影
- 力度：默认最轻、上限最轻——多一分就背叛她
- 肤色：完全真实，皱纹与瑕疵保留
- 不是：不是任何"风格化"——她的风格就是反风格
- 禁：一切风格化手法
- 一句话：平视的温柔

### 吴宇森语法（固定版）
- 色盘：冷蓝夜色 × 烛光/火光暖橙的双极对撞
- 光：伦勃朗烛光、枪口火光、教堂彩窗
- 手法元素：白鸽、慢镜飞散的碎片、风衣、烟
- 运动：慢镜芭蕾——跃起双枪、白鸽、碎片慢速悬浮；火光照亮慢动作
- 焦点：慢镜里主体锐利+碎片/烟雾拖影；仪式感浅景深
- 力度：默认中高、上限高——双极对撞要拉得开，但暗部绸缎黑要保留层次
- 肤色：伦勃朗式——半脸烛光暖、半脸夜色冷
- 不是：不是杜琪峰的冷静（他要浪漫与爆发）、不是港片的市井杂色
- 禁：均匀明亮、单调色温
- 一句话：圣洁与暴力的对撞

### 刘伟强语法（固定版）
- 色盘：双线——都市戏冷蓝钢灰（无间道线）、江湖夜戏保留庙街暖杂色（古惑仔线），按画面内容二选一，不混用
- 光：天台顶光、电梯/室内的冷白荧光、车灯的锐利点光；庙街线用霓虹杂光
- 手法元素：漫画改编的锐度（古惑仔/风云）、速度感（头文字D的弯道拖影）、干净利落的对峙构图
- 运动：速度感——弯道拖影、车灯拉丝；干净利落的剪辑节奏
- 焦点：商业锐利全景深；速度场景才允许车灯拉丝/弯道拖影
- 力度：默认中、上限中高——锐利优先于暗化
- 肤色：真实锐利不柔化，冷白或街灯杂色
- 不是：不是杜琪峰（他更商业更亮更锐）、不是王家卫（他不暧昧）
- 禁：昏黄怀旧、重颗粒、雾气弥漫
- 一句话：冷蓝锋利的商业江湖

### 关锦鹏语法（固定版）
- 色盘：怀旧胭脂红+月白+幽蓝（民国线）；现代线（蓝宇/愈快乐愈堕落）转冷蓝都市；低明度暖冷交织
- 光：绸缎般的柔光、幽怨的低调光、老式台灯/街灯
- 手法元素：旗袍质感、镜子与纱窗的朦胧、旧物细节（胭脂盒/怀表）、女性的凝视
- 运动：缓慢横移与凝视；纱与烟的慢速飘动；旧时光的静止感
- 焦点：浅景深+纱/镜前景的朦胧层次；凝视感柔光
- 力度：默认轻中、上限中——朦胧来自纱与镜，不来自模糊
- 肤色：绸缎柔光里的旧式美人，肤质柔但纹理在
- 不是：不是陈可辛的大众暖黄（他更幽更私）、不是许鞍华的平视（他有凝视）
- 禁：硬朗、强对比、现代感
- 一句话：旧时光里的幽怨与温柔

## 分片深度参考（学习用，非生产混用）

## 港片通性（黄金年代总风格）

从十位导演往上抽象的一层：无论江湖片、武侠片、警匪片、文艺片还是喜剧，黄金年代港片共享同一套视觉基因。

### 类型参考（对应分片库的位置）

| 类型 | 代表 | 港片通性的体现 |
|---|---|---|
| 江湖片 | 英雄本色/古惑仔 | 夜色蓝黑+霓虹+火光，庙街的暖杂色 |
| 武侠片 | 新龙门客栈/东方不败 | 大漠孤烟的暖金，客栈油灯，烟雨 |
| 警匪片 | 无间道/PTU | 冷蓝都市+稀疏发光体，夜的压迫 |
| 文艺片 | 花样年华/甜蜜蜜 | 暖黄怀旧、低调光、烟雾 |
| 喜剧 | 功夫/大话西游 | 高饱和市井暖金、黄昏 |
| 鬼片 | 倩女幽魂/回魂夜 | 幽蓝夜色+红衣/烛火 |

港片精髓：**三色混光**——钠灯橙黄街灯、荧光灯青白店铺、霓虹红品红招牌在同一帧里各自为政，这是港片与任何单一导演的最大区别（王家卫统一光色为情绪服务，杜琪峰把夜压成冷蓝，港片通用语法保留街头的杂）；**密度**（楼挤人、招牌挤招牌、光挤光）；**市井与宿命并存**（再浪漫的镜头底下也是大排档的油烟）。港片的"旧"是质感的旧：招牌褪色、骑楼斑驳、铁窗花、胶片颗粒——但永远干净不脏；"闹"是层次的闹：前景招牌、中景人、远景楼，闹而有序。日戏是亚热带硬阳光+过曝的天+海风灰蓝，夜戏是三色混光的层层叠加，都不是单色滤镜。

### 港片景别语法

| 景别/内容 | 手法 |
|---|---|
| 人物特写 | 钠灯橙黄或荧光青白贴脸（看场景来源物）+背景霓虹散景、浅景深、富士胶片颗粒、汗与肤质真实 |
| 中景/市井 | 茶餐厅/大排档/街市的三色混光（灯泡橙+荧光青白+窗外霓虹）、蒸汽升腾、人群层次 |
| 大景/城市 | 招牌森林+唐楼肌理、湿街反射、傍晚魔术时刻的蓝橙交错 |
| 夜景街道 | 三色混光全开：钠灯橙+荧光青白+霓虹红品红共存、湿沥青反射、出租车小巴红色顶灯 |
| 日戏/白天 | 亚热带硬阳光、轻微过曝的天、晒得发白的骑楼、海风灰蓝 |
| 雨景/天气 | 雨让三色光翻倍——反射加倍、伞的剪影、骑楼躲雨人 |
| 质感 | 富士胶片暖颗粒（夜景增感更粗）、略低对比不死黑、旧招牌肌理清晰、闹而有序 |

## 调用方式

用户点名风格 → 取该导演（可精确到片）的气质+对应景别语法写美学目标段；不点名 → 按「选型决策表」推荐 1-2 个并说明理由；不点名且不选导演时默认用「港片语法」（黄金年代总风格，与单导演并列）。
提示词结构不变：美学目标（导演阐述，含力度克制声明+可加的手法元素）+ 允许改动清单 + 严格保护清单 + 收尾「改完仍是印刷级海报，不是被滤镜洗过的照片」。
力度声明模板：「风格只做气质引导：保留原图全部细节与材质纹理，暗部保留层次不压死黑，偏色轻微，颗粒细腻——观者能感到导演气质，但画面仍然干净清晰。」
